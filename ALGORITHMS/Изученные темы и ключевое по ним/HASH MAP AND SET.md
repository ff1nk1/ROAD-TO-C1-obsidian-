==SET== нужен если задача состоит в том, чтобы проверить был ли элемент в списке до этого, среди обработанных. Например найти повторяющийся элемент в списке.
Другие примеры задач:
- Найти дубликаты
- Проверить уникальность элементов
- Проверить, встречался ли элемент раньше
- Найти общие элементы двух наборов
- Удалить дубликаты
- Проверить существование нужного значения


==HASH MAP== нужен в ситуации, когда нужно иметь какую-то связь между найденным объектом и чем-то ещё, например, задача Two Sum, где нужно найти ИНДЕКСЫ элементов, которые в списке в сумме дают какое-то заданное число, поэтому приходится хранить в словаре само число, которое уже БЫЛО при обходе списка, а так же его индекс
Другие примеры задач:
- Two Sum
- Подсчёт частот
- Группировка элементов
- Поиск элемента + информации о нём
- Маппинг одного значения на другое
- Проверка соответствий

**freq[x] = freq.get(x, 0) + 1** - проверка уникальности или количества повторений через хэш-таблицу
