Нужен в задачах, где для каждого элемента в данном списке нужно получить первый элемент, который первый справа или слева и больше или меньше этого.

Решается через монотонный стек.
В зависимости от задачи в стеке всегда содержится убывающая или возрастающая последовательность(если нужен больший, то возрастающая и наоборот)
Проходим данную последовательность слева-направо или справа-налево тоже в зависимости от задания(если нужно найти большие/меньшие справа, то идем слева-направо)

Алгоритм(если нужно найти для каждого элемента самый первый меньший для его справа):
	Если стек пустой, то кладем туда элемент и его индекс(нужен для задачи в основном)
	Если стек не пустой, то сравниваем последний добавленный элемент и взятый, если последний добавленный больше, то убираем элементы до того момента, пока последний не станет равным или меньше взятого и ложим туда взятый. А убранные элементы добавляем в финальный результат, прописывая им индекс взятого элемента, который их убрал(то есть для них всех он будет решением)

	Если в конце остались элементы, то для них нет меньшего справа.



Задача
Лайнландия представляет из себя одномерный мир, являющийся прямой, на котором располагаются N городов, последовательно пронумерованных от 0 до N - 1 . Направление в сторону от первого города к нулевому названо западным, а в обратную — восточным.

Когда в Лайнландии неожиданно начался кризис, все жители мира стали испытывать глубокое смятение. По всей Лайнландии стали ходить слухи, что на востоке живётся лучше, чем на западе.

Так и началось Великое Лайнландское переселение. Обитатели мира целыми городами отправились на восток, покинув родные улицы, и двигались до тех пор, пока не приходили в город, в котором средняя цена проживания была меньше, чем в родном.

## Формат ввода

В первой строке дано одно число N ( 2 ≤ N ≤ 1 05 2≤N≤105) — количество городов в Лайнландии. Во второй строке дано N чисел a i ai​ ( 0 ≤ a i ≤ 1 09 0≤ai​≤109) — средняя цена проживания в городах с нулевого по (N - 1)-й соответственно.

## Формат вывода

Для каждого города в порядке с нулевого по (N - 1)-ый выведите номер города, в который переселятся его изначальные жители. Если жители города не остановятся в каком-либо другом городе, отправившись в Восточное Бесконечное Ничто, выведите -1 .

### Пример

Ввод

```
10
1 2 3 2 1 4 2 5 3 1
```

Вывод

```
-1 4 3 4 -1 6 9 8 9 -1
```


Решение

```
import sys


def main():
    stack = list()
    res = list()
    N = int(input())
    l = input().split()


    for ind, num in enumerate(l):
        num = int(num)
        while len(stack) > 0 and stack[-1][0] > num: # Если элемент больше взятого, то убираем
            res.append((stack.pop()[1], ind))
        stack.append((num, ind))                     # Добавляем взятый

    for _, ind in stack:                             # индексируем оставшиеся в стеке -1
        res.append((ind, -1))
    res.sort()
    for ind, new_ind in res:
        print(new_ind, end=' ')

    pass
if __name__ == '__main__':
    main()
```
