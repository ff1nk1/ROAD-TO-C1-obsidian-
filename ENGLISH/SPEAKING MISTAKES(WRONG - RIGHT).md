
# !!!DONT USE WILL AFTER IF
## WORD ORDER
	❌The first step it's... - ✅ The first step is...

## "to + verb" mistakes
	❌ I really enjoy to communicate. -  ✅ I really enjoy communicating.
## BAD CONSTUCTIONS
	❌ Where is time doubled? - ✅ Where is the response time increasing?, 
							    ✅ Which component is slow?

	❌ How his version did pass the tests - ✅ **Whether his changes passed the tests (Проблемы HOW - тут не подойдет, нужно whether или if не задаю прямой вопрос ведь. Тут не вопроса, did не нужно)

	❌ How it deploying - ✅ Whether it deploys successfully

	❌The challenge is to do the fastest way... - ✅The challenge is finding the fastest way...

	❌It will be bad in production. - ✅It could cause problems in production.

	❌I will write my functions. - ✅I'll implement the feature or 
	✅I'll make the necessary changes.

	❌ My database has fault. - ✅ My database had an error. or ✅ There was an issue with the database.

	❌ Big emotions. - ✅ It was very emotional.

	❌ Find a language with everyone. - ✅ Get along with everyone.

	❌ I like to become smarter. - ✅ I enjoy learning new things.(enjoy всегда следующий глагол с ing enjoy improving, etc)

	✅proud of doing smth
